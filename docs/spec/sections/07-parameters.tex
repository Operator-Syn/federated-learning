\section{Tunable parameters}
\label{sec:parameters}

These are configuration, not constants. If the review of related literature concludes the
study needs a different facility spread, or the City Health Office supplies a different
reliability picture, the answer is a configuration change and a re-run. The table states who
may change each one, so that a number in the thesis can always be traced to a decision.

\subsection{The calibration profile}
A \emph{calibration profile} is one city's settings from this section, with a name and a version:
the facility count, each facility's reliability, latency and record volume, the participation floor,
and the target. Kept as its own record, it lets a later team rerun the comparison, with more
facilities or with corrected records, without reading back through this document to work out which
values produced an earlier result. A profile describes one data version. Change the records behind
it, and it needs recalibrating.
